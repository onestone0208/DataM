# 남은 작업 정리

## ✅ 1. 혼잡도 타깃 보강 (완료)
- ✅ 승·하차량 기반 체류 인원 근사 로직 구현 (Stock-Flow 미분방정식 기반)
- ✅ 지수 감쇠 모델 적용: `occupancy[t] = occupancy[t-1] * exp(-1/평균체류시간) + 승차 - 하차`
- ✅ 절대 체류 인원 중심의 혼잡도 CSV 생성 완료 (`data/혼잡도.csv`, 128K+ 레코드)

## ✅ 2. 그래프 및 노드 특징 생성 (완료)
- ✅ POI 카테고리 태깅 완료: 387개 POI → 11개 카테고리 자동 분류
- ✅ 역별 노드 특징 벡터 생성: 22개 역 × 24차원 특징
  - POI 밀도 특징 10개 (교육, 주거, 관공서, 상업, 의료 등)
  - 물리적 특징 6개 (위도/경도, 연면적, 층수, 노선순서 정규화)
  - 통계 특징 8개 (총 POI 수, 다양성 지수, 효과면적 등)
- ✅ 데이터 저장: `data/node_features.csv`, `data/node_features_info.json`

## ✅ 3. 시간/외생 특징 결합 (완료)
- ✅ 날짜별 특징 확장: 243일 × 29차원 특징 벡터 생성
  - 요일 one-hot (7개): 월~일 이진 인코딩
  - 기온 정규화 (3개): 평균/최저/최고 기온 [-1,1] 정규화
  - 순환 특징 (4개): 월/일 sin/cos 인코딩
  - 공휴일/휴일 (4개): 공휴일, 주말, 휴일, 평일 플래그
  - 계절 (4개): 봄/여름/가을/겨울 이진 인코딩
- ✅ 시간대별 특징 생성: 24시간 × 9차원 특징 벡터
  - 시간 순환 (2개): 24시간 sin/cos 인코딩
  - 시간대 구분 (5개): 출근/퇴근/점심/심야/주간 시간 플래그
- ✅ 데이터 저장: `data/temporal_features.csv`, `data/hour_features.csv`

## ✅ 4. 데이터 로더 및 텐서 구축 (완료)
- ✅ 슬라이딩 윈도우 시계열 데이터: 12시간 입력 → 1시간 예측
- ✅ 그래프 인접행렬 생성: 22×22 거리 기반 가중 그래프 (연결도 8.73)
- ✅ PyTorch Dataset 구축: train(2160), val(360), test(360) 시퀀스
- ✅ 배치 텐서 구조:
  - X: [12, 22, 2] (시간, 역, 특징) - occupancy, total_flow
  - Y: [22, 2] (역, 특징) - 예측 타깃
  - adjacency: [22, 22] - 그래프 인접행렬
  - node_features: [22, 16] - 역별 POI/물리적 특징
  - date_features: [21] - 날짜별 특징 (요일, 기온, 휴일 등)
  - time_features: [7] - 시간대별 특징 (출근/퇴근/심야 등)
- ✅ 데이터 저장: `train/val/test_dataset.pkl`, `adjacency_matrix.npy`

## 5. 모델 프로토타이핑
- 2-layer DCGRU(K=3) encoder + decoder 기반 DCRNN 골격 구현 및 Attention 모듈(additive/self) 실험.
- 혼잡도 MAE/Huber 기본 손실 외에 승·하차 예측을 포함하는 멀티태스크 손실 옵션을 비교.
- 학습/추론 스크립트 분리 및 하이퍼파라미터 설정 파일화.

## 6. 평가 및 해석
- 현재 sequential split을 사용해 최근 2~4주 홀드아웃 성능 리포트 생성.
- 요일/공휴일/기온 특성별 Stratified 지표와 ablation(기온·공휴일 feature 제거) 실험 스크립트 작성.
- Attention weight, 혼잡도 예측 vs. 실제 비교 그래프 등 해석용 시각화 노트북/스크립트 마련.

## 7. 제약 해소 계획
- 효과 면적 검증을 위한 외부 자료(역사 도면, 보도자료 등) 수집 채널 조사.
- 체류 추정 민감도 분석: 체류시간 가정 변화에 따른 혼잡도 변화를 기록하고 문서화.
- 강수 데이터 확보 방안(공공 API 등)과 라벨 버전 관리 전략을 문서화해 추후 갱신 시 추적 가능하게 유지.
