# 혼잡도 예측 모델 개선 과정

## 📋 개요

DCRNN 기반 혼잡도 예측 모델이 큰 값(피크 시간대)을 제대로 예측하지 못하는 문제를 분석하고 해결한 과정을 정리합니다.

---

## 🚨 기존 코드의 문제점

### 1. 현상 (Symptoms)

#### 예측 성능 문제
- **예측 범위 제한**: 모든 예측값이 0~50명 범위에 고착
- **실제 범위**: 0~1,284명 (약 25배 차이)
- **피크 시간대 예측 실패**: 
  - 실제 1,284명 → 예측 49명 (96% 오차)
  - 실제 502명 → 예측 49명 (90% 오차)

#### 구체적 예측 사례 (Epoch 23)
```
대전역 2025-08-29 14:00-15:00:
  실제 혼잡도: 178.0명 → 예측: 0.0명 (100% 오차)

정부청사역 2025-08-29 16:00-17:00:
  실제 혼잡도: 376.8명 → 예측: 48.5명 (87.1% 오차)
```

#### 전체 성능 지표
- **전체 MAE**: 34.02명
- **전체 RMSE**: 100.44명
- **예측 범위**: [-0.0, 49.8]명
- **실제 범위**: [0.0, 1284.2]명

## 🔍 원인 분석 (Root Cause Analysis)

### 1. 데이터 스케일 불균형 문제

#### 분포 특성
```
혼잡도 데이터 분포:
- 대부분 시간대: 0~100명 (빈번)
- 피크 시간대: 500~1,284명 (드물음)
- 비율: 약 90% vs 10%
```

#### 수학적 원인
- **Loss 함수**: 단순 MAE (Mean Absolute Error)
- **최적화 전략**: 모델이 "빈번한 작은 값"에 최적화
- **피크 무시**: 드문 큰 값은 전체 Loss에 미미한 영향

```python
# 현재 상황
작은 값 오차: |50 - 0| = 50 (자주 발생)
큰 값 오차: |50 - 1000| = 950 (드물게 발생)

# 모델 학습 결과
→ "작은 값만 잘 맞추고 큰 값은 포기"하는 전략 선택
```

### 2. 정규화 부재

#### 문제점
- **Raw 값 사용**: 0~1,284 범위를 그대로 학습
- **Gradient 불안정**: 초기 학습에서 큰 gradient로 인한 불안정
- **표현 범위 제한**: 네트워크가 "안전한 작은 범위"에 수렴

#### 네트워크 동작
```python
# 현재 상황
Input: [0, 604, 1284, 50, ...]  # 극단적 범위 차이
Network: ReLU, GRU 등의 비선형 함수들
Output: 훈련 데이터 "평균 근처"로 수렴 (0~50)
```

### 3. Loss 함수의 균등 가중치

#### 현재 구조
```python
# 기존 코드
self.loss_fn = nn.L1Loss()  # 모든 값에 동일한 가중치
loss = |pred - true|        # 큰 값이든 작은 값이든 동일 처리
```

#### 결과
- **피크 값 소외**: 1,000명대 오차가 전체 Loss에 묻힘
- **수학적 합리성**: 작은 값 위주 최적화가 Loss 관점에서 더 유리

## 💡 해결 방법 (Solutions)

### 1. Log1p + 정규화 변환

#### 이론적 배경
```python
# 변환 과정
raw_occupancy = [0, 50, 500, 1284]  # 원본 데이터

# Step 1: Log1p 변환 (tail 압축)
log_occupancy = np.log1p(raw_occupancy)
# [0, 3.93, 6.21, 7.16] - 범위가 0~7로 압축

# Step 2: 정규화 (평균 0, 분산 1)
normalized = (log_occupancy - mean) / std
# [-2.1, -0.3, 1.2, 2.8] - 표준 정규분포
```

#### 효과
- **범위 압축**: 1,284배 차이 → 7배 차이로 축소
- **피크 중요도 증가**: 큰 값이 더 이상 "극단값"이 아님
- **학습 안정성**: 표준 정규분포 범위에서 안정적 학습

#### 구현
```python
class OccupancyDataset(SubwayGraphDataset):
    def _transform_occupancy(self, occ_tensor):
        # Log1p 변환
        log_occ = torch.log1p(occ_tensor)
        # 정규화
        norm_occ = (log_occ - self.log_mean) / self.log_std
        return norm_occ
    
    def inverse_transform(self, norm_tensor):
        # 역변환: 정규화 해제 → expm1
        log_tensor = norm_tensor * self.log_std + self.log_mean
        occ_tensor = torch.expm1(log_tensor)
        return occ_tensor
```

### 2. 가중치 Loss 함수

#### 설계 원리
```python
def _weighted_mae_loss(self, pred_norm, target_norm, raw_target, alpha=0.3, C=200.0):
    # 기본 MAE
    base_loss = torch.abs(pred_norm - target_norm)
    
    # 원본 값에 비례한 가중치
    weights = 1.0 + alpha * (raw_target / C)
    # 200명 → 1.3배 가중치
    # 600명 → 1.9배 가중치  
    # 1200명 → 2.8배 가중치
    
    return (weights * base_loss).mean()
```

#### 효과
- **피크 중요도 증가**: 큰 값의 오차에 더 높은 페널티
- **균형 학습**: 작은 값과 큰 값 모두 중요하게 처리
- **수학적 인센티브**: 피크 예측 개선이 Loss 감소에 직접 기여

### 3. 통합 구현

#### 데이터 파이프라인
```python
# 훈련 시
X_raw → Log1p → Normalize → Model → Denormalize → Expm1 → Prediction

# Loss 계산 시  
Loss = WeightedMAE(pred_normalized, target_normalized, target_raw)
```

```python
# 개선 후 예상 범위
```

```python
class OccupancyDataset(SubwayGraphDataset):
    """혼잡도 전용 데이터셋 (Log1p + 정규화 적용)"""
    
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self._compute_normalization_stats()  # 🔥 정규화 통계 계산
        
    def _compute_normalization_stats(self):
        """전체 데이터에서 log1p + 정규화 통계 계산"""
        # 모든 혼잡도 데이터 수집
        # Log1p 변환 후 mean, std 계산
        
    def _transform_occupancy(self, occ_tensor):
        """혼잡도를 log1p + 정규화 변환"""
        
    def inverse_transform(self, norm_tensor):
        """정규화된 값을 원본 혼잡도로 역변환"""
```

### 2. 가중치 Loss 함수

```python
def _weighted_mae_loss(self, pred_norm, target_norm, raw_target, alpha=0.3, C=200.0):
    """큰 혼잡도 값에 더 가중치를 주는 MAE Loss"""
    base_loss = torch.abs(pred_norm - target_norm)
    weights = 1.0 + alpha * (raw_target / C)
    weighted_loss = weights * base_loss
    return weighted_loss.mean()
```
