# 🚇 대전 지하철 혼잡도 예측 시스템 - 프로젝트 현황

## 📊 **프로젝트 개요**
- **목표**: GNN 기반 지하철 역 내 혼잡도 실시간 예측
- **기간**: 2025년 1월 ~ 현재
- **데이터 범위**: 대전교통공사 1호선 22개 역, 243일간
- **핵심 기술**: DCRNN + Attention, Stock-Flow 모델링

## ✅ **완료된 작업 (6/6 단계)**

### 1️⃣ **혼잡도 타깃 보강** ✅
- **Stock-Flow 미분방정식** 기반 체류 인원 추정
- **지수 감쇠 모델**: `occupancy[t] = occupancy[t-1] × 0.0183 + 승차 - 하차`
- **데이터 규모**: 128,306개 레코드 (11.8MB)
- **물리적 타당성**: 음수 방지, 시간 연속성 보장

### 2️⃣ **그래프 및 노드 특징 생성** ✅
- **POI 자동 분류**: 387개 시설 → 11개 카테고리 (90.2% 정확도)
- **노드 특징**: 22개 역 × 16차원 (POI 밀도 + 물리적 특성)
- **그래프 구조**: 22×22 거리 기반 가중 인접행렬 (연결도 8.73)

### 3️⃣ **시간/외생 특징 결합** ✅
- **날짜별 특징**: 243일 × 24차원 (요일, 기온, 공휴일, 계절)
- **시간대별 특징**: 24시간 × 9차원 (출근/퇴근/심야 구분)
- **실용성 우선**: 정규화 최소화, 직관적 해석

### 4️⃣ **데이터 로더 및 텐서 구축** ✅
- **PyTorch Dataset**: train(1992), val(444), test(480) 시퀀스
- **슬라이딩 윈도우**: 12시간 입력 → 1시간 예측
- **배치 구조**: [시간, 역, 특징] + 그래프 + 메타데이터

### 5️⃣ **모델 프로토타이핑** ✅
- **DCRNN + Attention** 구현 완료
- **모델 구조**: 2-layer DCGRU(K=3) encoder-decoder
- **파라미터 수**: 565,949개 (hidden_size=64)
- **Node features 정규화**: 입력 스케일 불일치 문제 해결
- **학습 설정**: Adam optimizer, CosineAnnealingLR scheduler

### 6️⃣ **평가 및 해석** ✅
- **데이터 분할**: 계절별 균등 분할 (Train: 166일, Val: 37일, Test: 40일)
- **Best 모델 성능** (Epoch 14):
  - **MAE**: 18.91명 (↓ 47.6% vs Epoch 1)
  - **RMSE**: 49.12명 (↓ 49.4% vs Epoch 1)
  - **MAPE**: 52.7% (↓ 38.5% vs Epoch 1)
  - **R²**: 0.782 (↑ 428% vs Epoch 1)
  - **예측 범위**: [-0.0, 989.3]명
- **문제 해결**: 역별 고정값 패턴 문제 완전 해결

## 🎯 **핵심 기술 스택**

### **데이터 처리**
- **Python**: pandas, numpy (전처리)
- **PyTorch**: Dataset, DataLoader (모델링)
- **geopy**: 지리적 거리 계산

### **특징 공학**
- **POI 분류**: 키워드 기반 자동 태깅

- **그래프 구성**: 거리 기반 Gaussian kernel

### **모델 아키텍처** ✅

- **Attention**: Additive attention 메커니즘
- **Encoder-Decoder**: 12시간 입력 → 1시간 예측
- **파라미터**: 565,949개 (hidden_size=64, input_size=47, output_size=1)
