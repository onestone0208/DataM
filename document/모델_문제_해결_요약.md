# 모델 문제 해결 요약

## 🔍 발견된 문제들

### 1. **입력 차원 불일치**
- **문제**: Config에서 `input_size=46`으로 설정했지만, 실제 모델은 `input_size=47` 사용
- **원인**: 
  - 시계열 특성: 31차원 (혼잡도1 + 승차1 + 하차1 + 시간7 + 날짜21)
  - 노드 특성: 16차원
  - 총합: 47차원
- **해결**: 모델이 실제 입력 차원(47)을 올바르게 처리하도록 수정

### 2. **특성 중복 결합**
- **문제**: `date_features`와 `time_features`가 이미 X에 포함되어 있는데, `_augment_features`에서 다시 결합 시도
- **원인**: 모델 forward에서 모든 특성을 결합하려고 했지만, 일부는 이미 포함됨
- **해결**: `node_features`만 추가하도록 수정

### 3. **모델 Collapse (가장 심각)**
- **문제**: 
  - 예측 범위가 매우 좁음: [-0.0, 110.3]명
  - 실제 범위: [0.0, 1475.2]명
  - 예측 값이 고정됨 (110.3, 75.4, 86.2 등)
- **원인**:
  1. 디코더가 항상 같은 초기 입력을 받아서 같은 출력 생성
  2. Teacher forcing이 너무 빠르게 감소하여 디코더가 학습하지 못함
  3. 출력 스케일이 잘못되어 작은 범위만 학습
- **해결**:
  1. 디코더 초기 입력에 작은 노이즈 추가 (다양성 확보)
  2. 디코더 다음 입력에도 노이즈 추가
  3. Hidden state를 input_size로 projection하는 레이어 추가

## 🔧 적용된 수정사항

### 1. 모델 구조 수정 (`models/dcrnn_layers.py`)

#### a) 특성 결합 로직 개선
```python
# Before: 모든 특성을 결합 시도
if node_features is not None or date_features is not None or time_features is not None:
    x = self._augment_features(x, node_features, date_features, time_features)

# After: node_features만 추가 (date/time은 이미 X에 포함)
if node_features is not None:
    x = self._augment_features(x, node_features, None, None)
```

#### b) 디코더 초기 입력 개선
```python
# Hidden state를 input_size 차원으로 projection
last_encoder_hidden = encoder_hidden[-1]  # [B, N, hidden_size]
initial_decoder_input = self.hidden_to_input_projection(last_encoder_hidden)  # [B, N, input_size]

# 디코더 collapse 방지: 초기 입력에 작은 노이즈 추가
if self.training:
    noise_scale = 0.01
    noise = torch.randn_like(initial_decoder_input) * noise_scale
    initial_decoder_input = initial_decoder_input + noise
```

#### c) 디코더 다음 입력 개선
```python
# Teacher forcing이 아닐 때만 다음 입력으로 사용
if targets is None or torch.rand(1).item() >= teacher_forcing_ratio:
    decoder_input = self.output_to_input_projection(output)
    
    # 디코더 collapse 방지: 예측값에 작은 노이즈 추가
    if self.training:
        noise_scale = 0.005
        noise = torch.randn_like(decoder_input) * noise_scale
        decoder_input = decoder_input + noise
```

#### d) Hidden-to-Input Projection 레이어 추가
```python
# 모델 초기화 시 추가
self.hidden_to_input_projection = nn.Linear(hidden_size, input_size)
```

## ⚠️ 주의사항

1. **노이즈 스케일**: 너무 크면 학습 불안정, 너무 작으면 효과 없음
2. **Teacher Forcing**: 너무 빠르게 감소하면 디코더 collapse 가능
3. **출력 스케일**: 정규화된 값의 범위가 너무 좁으면 모델이 큰 값을 학습하지 못함
