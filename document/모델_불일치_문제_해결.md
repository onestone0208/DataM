# 모델 구조 불일치 문제 해결

## 🔍 문제 분석 (사용자 분석 정확함)

### 핵심 문제
**완전히 다른 설정으로 학습된 옛날 모델을, 지금 구조에 억지로 끼워맞춰서 평가하고 있음**

### 확인된 사실

1. **체크포인트 Config**:
   - `input_size: 46`
   - `output_size: 2`
   - Epoch: 35

2. **체크포인트 실제 State Dict**:
   - Encoder 첫 레이어: `[3, 47, 128]` → **실제 input_size = 47**
   - Output projection: `[1, 128]` → **실제 output_size = 1**

3. **평가 스크립트**:
   - Config를 보고 `input_size=46, output_size=2`로 모델 생성 시도
   - 하지만 실제로는 `input_size=47, output_size=1`로 강제 생성
   - State Dict 로드 시 shape mismatch 발생

### 왜 이런 일이 발생했나?

1. **학습 중 구조 변경**: 
   - 처음에는 `input_size=46, output_size=2`로 학습 시작
   - 중간에 `input_size=47, output_size=1`로 변경
   - 그 상태로 저장됨
   - **하지만 Config는 업데이트되지 않음**

2. **평가 스크립트의 잘못된 가정**:
   - Config를 신뢰하고 모델 생성
   - 실제 State Dict 차원과 불일치

### 결과

- 모델이 **역별 고정값**만 출력 (110.3, 75.4, 86.2 등)
- 예측 범위가 매우 좁음: [0, 110.3]명
- 실제 범위: [0, 1475.2]명
- **모델이 collapse된 것이 아니라, 잘못된 구조에 억지로 끼워맞춘 결과**

## ✅ 해결 방법

### 1. 즉시 해결 (평가 스크립트 수정)

**`evaluate_occupancy_seasonal.py` 수정 완료**:
- State Dict에서 실제 차원을 확인
- 실제 차원에 맞게 모델 생성
- `strict=False`로 누락된 레이어 허용

```python
# 실제 State Dict에서 차원 확인
encoder_key = 'encoder_layers.0.reset_gate_x.weight_forward'
actual_input_size = state_dict[encoder_key].shape[1]  # 47

output_key = 'output_projection.weight'
actual_output_size = state_dict[output_key].shape[0]  # 1

# 실제 차원으로 모델 생성
model = DCRNN(
    input_size=actual_input_size,  # 47
    output_size=actual_output_size,  # 1
    ...
)
```

### 2. 근본 해결 (모델 재학습)

**새 구조로 모델을 재학습해야 함**:

1. **체크포인트 디렉토리 정리**:
   ```bash
   # 옛날 체크포인트 백업
   mv checkpoints/occupancy_model checkpoints/occupancy_model_old
   mkdir checkpoints/occupancy_model
   ```

2. **새 구조로 학습**:
   ```bash
   python scripts/train_occupancy_model.py
   ```

3. **학습 중 Config 업데이트 확인**:
   - 학습 스크립트가 올바른 Config를 저장하는지 확인
   - `save_checkpoint()` 함수에서 Config 저장 확인

### 3. 체크포인트 저장 개선

**학습 스크립트에서 Config 저장 시 실제 모델 구조 사용**:

```python
def save_checkpoint(self, is_best: bool = False):
    checkpoint = {
        'epoch': self.current_epoch,
        'model_state_dict': self.model.state_dict(),
        'config': {
            'model': {
                'input_size': self.model.input_size,  # 🔥 실제 모델 값 사용
                'output_size': self.model.output_size,  # 🔥 실제 모델 값 사용
                ...
            }
        }
    }
```
