[목표]
현재 확보한 데이터(승·하차량, 역 정보, POI, 공휴일, 기온)를 활용해 DCRNN + Attention 기반 시공간 모델로 역 내 혼잡도를 예측하는 파이프라인 구축

[데이터 자원 및 활용]
1. `data/승하차.csv`
   - 역·날짜·방향별 1시간 집계 ⇒ 24시간 시계열 텐서로 변환하고, 승차/하차를 별도 채널로 유지
2. `data/지도.csv`
   - 역 좌표, 구간 거리, 연면적, 층수 ⇒ 방향 그래프 인접행렬(거리 기반 가중치) 생성 + 연면적/층수로 면적 근사치 계산
3. `data/주요장소.csv`
   - 출구별 주요시설 좌표 ⇒ 역별 POI 밀도/카테고리 비율로 node feature 확장
4. `data/공휴일.csv`
   - 공휴일·대체휴일 플래그 ⇒ 요일/계절성 이외의 이벤트성 시간 특징으로 사용
5. `data/기온.csv`
   - 일별 평균·최저·최고 기온 ⇒ 시계열에 조인해 계절성/기상 영향 feature로 주입
[모델/파이프라인 계획]
1. 혼잡도 지표 정의
   - `혼잡도 = 추정 체류 인원(절대값)`을 기본 타깃으로 삼고, 필요 시 승강장/대합실별 분리 값을 추가 산출
   - 연면적·층수 기반 효과 면적은 보조 설명 변수로만 사용하고, 최종 지표는 시간대별 절대 체류 인원으로 정규화 없이 유지
   - 승·하차량으로 체류 인원을 근사: 이동 평균 체류 시간 가정을 두고 입장·퇴장 누적을 업데이트하여 절대 체류 인원을 계산

2. 특징 엔지니어링
   - 시계열 입력: 과거 T시간(예: 12시간) 승차/하차 + 혼잡도 지표를 스택
   - 노드 특징: POI 통계, 면적 근사값, 역순서, 구간 거리, 좌표
   - 시간 특징: 요일 one-hot, 공휴일 플래그, 기온(평균/최대/최소), 시간대 sin/cos

3. DCRNN + Attention 모델
   - Encoder: 2-layer DCGRU(K=3)로 시공간 확산을 학습
   - Decoder: DCGRU 기반 seq2seq에 additive/self-attention을 추가해 과거 hidden state에 가중치를 두고 다중 타임스텝 예측
   - Loss: MAE/Huber (혼잡도 타깃), 보조로 승·하차 예측 오차를 함께 최소화하는 멀티타스크 옵션 검토

4. 검증 및 해석
   - 시계열 홀드아웃(최근 2~4주) + 요일/공휴일별 stratified 평가
   - 기온/공휴일 feature의 효과를 ablation으로 확인
   - Attention weight 시각화로 혼잡 패턴 해석 자료 생성

5. 운영 고려
   - 예측 혼잡도가 임계값 초과 시 알람을 발생시키는 룰 정의
   - 추론 파이프라인을 배치 스케줄(예: 1시간 간격)로 자동화

[제약 및 추가 확보 필요]
1. 면적 근사 검증
   - 연면적·층수만으로 계산한 효과 면적이 실제 승강장/대합실 규모를 얼마나 반영하는지 확인할 외부 자료(보도자료, 시설 소개 등)가 필요
2. 체류 인원 검증
   - 승·하차 기반 체류 추정치의 정확도를 교차검증할 현장 조사나 운영 보고서가 없으므로, 추정 모델의 민감도 분석을 병행
3. 기상 보강
   - 강수량/강수여부 데이터를 추가 확보하거나 공개 API로 보완하면 악천후 패턴을 더 잘 포착 가능
4. 라벨 품질
   - 혼잡도 지표가 전적으로 추정치에 의존하므로, 추후 표본 관측이 확보되면 재보정할 수 있도록 로깅/버전관리가 필요
