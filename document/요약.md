## 1. DCRNN – Diffusion Convolutional Recurrent Neural Network 

### 한 줄 번역 요약

> “도로 센서를 정점으로 하는 **방향 그래프** 위에서 교통을 **확산(diffusion) 과정**으로 보고, 그 위에 **확산 컨볼루션 + RNN(seq2seq)** 을 얹어서 장기 교통 예측을 한다.”

### (1) 기존 연구 & 한계

* **전통 통계 모델**: ARIMA, Kalman filter 등

  * 시계열의 **정상성 가정**을 전제로 해서, 러시아워·사고 같은 **비정상 패턴**에 약함. 
* **딥러닝 기반 시계열 모델**:

  * LV(2015), Yu(2017) 등은 RNN으로 시간적 의존성만 보고, **공간 구조(도로 네트워크)** 를 제대로 안 씀. 
* **CNN/GCN 기반 공간 모델**:

  * 이미지를 전제로 하는 2D CNN → 도로 네트워크는 **비유클리드**라 안 맞음.
  * Spectral GCN(ChebNet 등)은 **무방향 그래프** 전제라, 상·하류가 다른 교통의 **비대칭성**을 표현하기 어려움. 

### (2) 새로 제안한 핵심 기술

#### ① 교통을 “방향 그래프 위 확산 과정”으로 모델링

* 센서 네트워크를 **가중 방향 그래프** (G=(V,E,W))로 정의

  * 정점: 센서
  * 간선 가중치: **도로망 거리 기반 proximity** (thresholded Gaussian kernel) 
* **랜덤워크 + 재시작 확률 α** 를 이용해 확산을 정의:

  * 전이행렬: (D_O^{-1}W) (out-degree 정규화)
  * 무한 step 랜덤워크의 가중합으로 stationary distribution (P)를 유도, 실 구현은 **K-step로 truncate**. 

#### ② Diffusion Convolution (그래프 컨볼루션 정의)

* 각 feature 채널 p에 대해:
  [
  X_{:,p} **{G} f*\theta = \sum_{k=0}^{K-1}
  \big[\theta_{k,1}(D_O^{-1}W)^k + \theta_{k,2}(D_I^{-1}W^\top)^k\big] X_{:,p}
  ]
* 포인트:

  * **정방향·역방향 랜덤워크** 둘 다 사용 → 상류/하류 영향 동시에 반영.
  * 그래프가 희소하면, **시간복잡도 O(K|E|)** 로 계산 가능. 
* 부록에서, **ChebNet spectral convolution이 이 diffusion conv의 특수 케이스**임도 보여줌. 

#### ③ DCGRU + Seq2Seq + Scheduled Sampling

* 기존 GRU에서 **W·x + U·h** 부분을 그냥 matmul 대신 **diffusion conv**로 교체 → **DCGRU**:

  * reset/update gate, candidate state 계산에 모두 ?₍G₎ 연산 사용. 
* **Encoder–Decoder (seq2seq)** 구조로 여러 step 예측:

  * Encoder: 과거 시계열 입력
  * Decoder: 한 스텝씩 예측을 뽑아나가는데,

    * 학습 시: 일정 확률 εᵢ로 **정답(y*)** 를, 1−εᵢ로 **모델 예측(ŷ)** 을 다음 입력으로 넣는 **Scheduled Sampling** 사용.
    * 테스트 시: 항상 자신의 예측을 넣음. 

### (3) 구현 관점 요약

1. **그래프 구성**

   * 센서 좌표 + 도로망 거리 계산 → 거리 σ, threshold κ로 adjacency W 계산 (Gaussian kernel). 
2. **모델 구조**

   * Encoder/Decoder 각각 DCGRU 레이어 2개, hidden size 64, diffusion step K=3. 
3. **학습**

   * Adam, 학습률 decay, MAE loss, scheduled sampling(역시그모이드로 εᵢ 감소).
4. **실험**

   * METR-LA, PEMS-BAY 15/30/60분 예측에서 ARIMA, VAR, SVR, FC-LSTM, STGCN 등 대비 **12–15% 성능 향상**.

## 2. STGCN-Metro – Spatiotemporal GCN for Metro Flow 

### 한 줄 번역 요약

> “도시 전체 지하철 역 네트워크를 그래프로 보고, **Dilated CNN(시간) + Cluster-GCN(공간)** 을 섞은 **STGCN 블록**으로 역별 승하차 인·아웃 플로우를 예측한다.”

### (1) 기존 연구 & 한계

* **통계 모델**: HA, ARIMA/SARIMA, Kalman, GARCH+ARIMA 등

  * 선형·정상성 가정, 공간 구조 미반영. 
* **머신러닝**: KNN, SVR, SVM, (개선형 KNN, LS-SVM 등)

  * 비선형은 잡지만, **특성 추출(feature engineering)** 에 강하게 의존. 
* **딥러닝**

  * RNN/LSTM/GRU: 시간은 잘 모델링하지만 **공간 의존성 무시**.
  * CNN/ConvLSTM: grid 기반이라 역 네트워크처럼 **불규칙 그래프**에는 부적합. 
  * GCN/TGCN/STGCN: 그래프는 쓰지만,

    * 전체 그래프에서 이웃 확장이 커지면 계산량+메모리 폭증,
    * spatial heterogeneity(역별 성격 차이) 고려 부족, over-smoothing 문젠 여전. 

### (2) 새로 제안한 핵심 기술: STGCN-Metro

#### ① ST-Conv Block 구조

* Figure 1(페이지 3)의 프레임워크:

  * **[Temporal DCNN + GLU] → [Cluster-GCN] → [Temporal DCNN + GLU]** 형태의 블록 2개를 쌓고, 마지막에 FC 출력층. 

#### ② 시간축: Dilated CNN + GLU

* 입력: X ∈ ℝ^{N×F×T} (역 N개, feature F, 시간 길이 T).
* Dilated 1D CNN 두 개 (dilation=1,2)로 멀리 떨어진 시점까지 한 번에 보는 **large receptive field** 확보. 
* 각 convolution 뒤에 **Gated Linear Unit(GLU)**:
  [
  H = g(X * k_1 + b)\ ⊙ \sigma(X * k_2 + c)
  ]

  * g: 활성함수, σ: sigmoid, ⊙: element-wise product
  * 필요 없는 시간 정보는 gating으로 차단 → 비선형 시계열에 잘 대응. 

#### ③ 공간축: Cluster-GCN

* 기본 GCN은 레이어가 늘면 **이웃 확장 → 전체 그래프**까지 퍼져서:

  * 메모리/계산량 부담,
  * 노드 표현이 비슷해지는 over-smoothing 발생.
* **Cluster-GCN** 아이디어 적용:

  * 그래프 클러스터링으로 정점을 여러 **서브그래프**로 나눔.
  * 학습 시, 각 서브그래프를 minibatch처럼 사용해 GCN 연산 → 메모리 절약, 이웃 확장을 subgraph 안으로 제한. 
* 레이어 공식:
  [
  X^{l+1} = \sigma\big((\tilde A + \lambda,\mathrm{diag}(\tilde A)) X^l W^l\big)
  ]

  * (\tilde A = (D+I)^{-1}(A+I)): 정규화 adjacency
  * λ: 학습 가능한 스칼라. 

#### ④ 거리 기반 가중 adjacency

* 역 i, j 간 **노선 거리를 dᵢⱼ**로 두고,
  [
  W_{ij} = \exp\left(\frac{d_{ij}-\mu}{\sigma}\right) \ (i\neq j)
  ]

  * μ, σ: 거리 분포의 평균과 표준편차
  * 가까울수록 큰 가중치 → 지리적 거리 반영. 

### (3) 구현 & 실험

1. **데이터**

   * 상하이 지하철 14개 노선, 289개 역 (2015.4.1~4.30).
   * 6:00~23:00, 5분 단위 집계 → 역당 1일 204 포인트. 카드 스와이프 데이터로 in / out flow 구분. 
2. **실험 세팅**

   * 입력: 지난 12윈도(1시간)를 보고, **다음 5분** inflow/outflow 예측.
   * PyTorch, MSE loss, Adam, batch=64, lr=0.001, epochs=100. 
3. **결과**

   * Baseline: HA, GRU, LSTM, GCN, TGCN, STGCN.
   * STGCN-Metro가 in/out 모두에서 **MAE, RMSE 최소**, 특히 **출퇴근 피크 시간**에서 더 민감하고 정확한 예측(그림 4,5 시각화).

## 3. ST-MetaNet+ – Spatio-Temporal Meta Learning 

### 한 줄 번역 요약

> “각 위치의 **지리 정보(POI, RN 등) + 현재 교통 상태**를 입력으로 받아, 그에 맞는 **GAT·GRU의 가중치를 메타러닝으로 생성**해서, 위치별·상황별로 다른 ST 상관 구조를 학습하는 모델.”

### (1) 문제 정의 & 기존 한계

* 교통에는:

  1. **복잡한 ST 상관**:

     * 시간: 사고/러시아워 후로 한동안 영향을 끼침.
     * 공간: 도로 연결 관계 따라 상하류에 전파. 
  2. **공간적 다양성(spatial diversity)**:

     * 위치마다 주변 POI, 도로 밀도, 차선수/제한속도 등 **node/edge attribute**가 다름 → ST 패턴도 다름. 
  3. **시간적 다양성(temporal diversity)**:

     * 평소 고속도로(고속 통과) vs 사고 후 정체(흐름이 정체를 더 악화시킴)처럼, **traffic state에 따라 ST 상관 구조 자체가 바뀜**. 

* 기존 딥러닝 연구:

  * DCRNN, STGCN류: **하나의 공유 모델**로 모든 위치를 처리 → 위치별·상황별 차이를 표현하기 어려움. 
  * Multi-task (위치별 서브모델 + similarity regularization): 위치 유사도를 가정해야 하고, side info가 약해서 불안정. 

### (2) 제안 기법: 메타러닝 기반 ST-MetaNet+

전체는 **Seq2Seq 구조**: encoder가 과거를 읽고, decoder가 step-by-step 예측. 두 쪽 모두 **Meta-GAT+ (공간) + Meta-GRU+ (시간)** 층을 가진다. 

#### ① Meta-Knowledge Learner (NMK/EMK)

* Node attributes v⁽ⁱ⁾ (POI, RN 통계, 위치 좌표 등) → FCN → **NMK(v⁽ⁱ⁾)** (노드 메타지식).
* Edge attributes e⁽ⁱʲ⁾ (도로 연결, 거리 등) → FCN → **EMK(e⁽ⁱʲ⁾)**. 
* 이 벡터들이 “이 위치/간선은 이런 종류의 ST 패턴을 가질 것 같다”는 **압축된 표현** 역할.

#### ② Meta-GAT+ (공간 메타러닝 GAT) 

* 입력: 현재 시점 hidden state들 (H = [h^{(1)},...,h^{(N)}]).
* 1단계: FC로 h → h′ 로 투영.
* 각 간선 (i,j)에 대해:

  * 메타지식:
    [
    MK^{(ij)} = NMK(v^{(i)}) \Vert NMK(v^{(j)}) \Vert EMK(e^{(ij)})
    ]
  * traffic context: context learner(CL_GAT)를 h′(i), h′(j)에 적용해 **TC⁽ⁱʲ⁾** 계산.
  * fusion gate:
    [
    FI^{(ij)} = \tanh(MK^{(ij)}) \odot \sigma(TC^{(ij)})
    ]
    → 현재 상태에서 MK의 어떤 차원이 중요할지 σ(TC)가 gating.
  * meta learner g_W, g_b가 FI⁽ⁱʲ⁾를 받아, **그 간선 전용 FC 파라미터 W⁽ⁱʲ⁾, b⁽ⁱʲ⁾** 생성.
  * 이 FC로 attention score a(h′(i),h′(j),...) 계산 → softmax → α⁽ⁱʲ⁾.
* 2단계: attention-weighted sum:
  [
  \bar h^{(i)} = U h^{(i)} + ReLU\Big(\sum_{j\in N_i} \alpha^{(ij)} h′^{(j)}\Big)
  ]

  * U는 shortcut(잔차 연결)용.

> 즉, “각 간선마다 지리+현재상태에 따라 **다른 attention 네트워크**를 메타러닝으로 생성해서, 그래프 상의 공간 상관을 모델링”.

#### ③ Meta-GRU+ (시간 메타러닝 RNN) 

* 각 노드 i, 시점 t에 대해:

  * context learner(CL_GRU): z⁽ⁱ⁾ₜ (입력) → traffic context TC⁽ⁱ⁾ₜ.
  * fusion gate:
    [
    FI^{(i)}_t = \tanh(NMK(v^{(i)})) \odot \sigma(TC^{(i)}_t)
    ]
  * meta learner g_W, g_U, g_b: FI로부터 **각 노드·시점별 GRU 파라미터** (W^{(i)}*{t,\Omega},U^{(i)}*{t,\Omega},b^{(i)}_{t,\Omega}) 생성 (Ω = u,r,h).
  * 이 파라미터를 사용해 GRU 업데이트:
    [
    h^{(i)}*t = GRU(z^{(i)}*t, h^{(i)}*{t-1} | W^{(i)}*{t,\Omega}, U^{(i)}*{t,\Omega}, b^{(i)}*{t,\Omega})
    ]
* → 위치마다, 그리고 시간 상태마다 **다른 GRU 동역학**을 갖게 됨.

### (3) 구현 & 실험

1. **데이터/태스크** 

   * Taxi-BJ: 베이징 32×32 grid, TDrive 택시 inflow/outflow, POI 668종 + 도로 8개 속성을 이용한 node/edge feature.
   * METR-LA & PEMS-BAY: 교통 속도 센서 (DCRNN 데이터와 동일), node feature는 GPS + k-NN road distance, edge feature는 거리.
2. **모델 세부 설정**

   * NMK/EMK Learner: 2-layer FCN, hidden {8,16,32,64} grid search.
   * Meta-GAT+/GRU+ hidden 차원 {16,32,64} 실험.
   * meta learner FCN: hidden [d_g, n] (n은 생성할 파라미터 수), d_g∈{1,2,4,8}. 
   * Seq2Seq, scheduled sampling(역시그모이드), Adam, gradient clipping.
3. **비교 모델**

   * HA, ARIMA, GBRT, Seq2Seq, GAT-Seq2Seq, ST-ResNet, STDN, DCRNN, Graph WaveNet, ST-MetaNet(이전 버전). 
4. **결과**

   * 세 데이터셋 모두에서 **ST-MetaNet+가 최상위 MAE/RMSE**.
   * Taxi-BJ 같이 지리 정보가 풍부할수록, DCRNN/Graph WaveNet 대비 **상당한 개선**. 
   * Ablation:

     * GAT/GRU → Meta-GAT/Meta-GRU → Meta-GAT+/Meta-GRU+ 순으로 점진적 개선.
     * 특히 **traffic context를 추가한 + 버전**이 sudden change(혼잡 시작 시점)에서 성능 향상. 
   * 메타지식 평가:

     * node embedding 공간에서 k-NN을 뽑으면, 실제 traffic 패턴(CORR, CORT)이 GAT-Seq2Seq보다 더 유사 → **지리+교통 특성을 잘 보존하는 임베딩** 획득.

## 정리해보면…

* **DCRNN**:

  * “그래프 위 확산”이라는 물리적 해석을 바탕으로 **방향 그래프용 GCN(확산컨브) + RNN(seq2seq)** 를 결합 → 기존 CNN/GCN/RNN 대비 **공간·시간 동시 모델링**을 깔끔하게 한 1세대 GNN 기반 교통 모델.

* **STGCN-Metro**:

  * STGCN 계열을 **메트로망**에 맞게 튜닝:

    * 시간: Dilated CNN + GLU
    * 공간: Cluster-GCN으로 서브그래프 샘플링 → 계산 효율 + over-smoothing 완화.

* **ST-MetaNet+**:

  * “각 위치와 현재 상태에 따라, **모델 자체의 파라미터를 바꿔버리자**”는 관점.
  * geo-graph attribute와 traffic state를 **메타 입력**으로 받아 GAT·GRU 가중치를 생성하는 **weight-generation meta learning** 프레임워크.

혹시 이 중에서 **직접 구현해보고 싶은 모델**이 있으면,
예를 들어 “PyTorch로 DCRNN/Meta-GAT+ 최소 버전 코드 구조짜기” 같이 구체적으로 잡아서 한 편씩 같이 뜯어볼까?
