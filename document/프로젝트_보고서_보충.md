## 3. 혼잡도 모델링

### 3.1 Stock-Flow 미분방정식 기반 체류 인원 추정

**수학적 모델**:
```
dOccupancy/dt = Inflow(t) - Outflow(t) - λ·Occupancy(t)

이산화:
occupancy[t] = occupancy[t-1] × exp(-1/τ) + boarding[t] - alighting[t]
```

**파라미터**:
- **평균 체류시간 (τ)**: 15분 (기본값)
- **감쇠 계수**: exp(-4) ≈ 0.0183
- **물리적 의미**: 자연스러운 승객 유출 모델링

**검증 결과**:
- 총 128,306개 혼잡도 레코드 생성
- 음수 방지 로직으로 물리적 타당성 보장
- 시간적 연속성 확보 (이전 시점 정보 활용)

### 3.2 혼잡도 지표
```python
# 주요 지표
occupancy: 추정 체류 인원 (명)
total_flow: 시간당 총 통행량 (명/시간)  
density: 인구 밀도 (명/㎡)
```

## 9. DCRNN 모델 아키텍처

### 9.1 모델 구조 개요

**DCRNN (Diffusion Convolutional Recurrent Neural Network)**
- **아키텍처**: Encoder-Decoder + Attention Mechanism
- **파라미터 수**: 565,949개
- **핵심 기술**: Diffusion Convolution + GRU + Attention

```python
# 모델 설정
input_size: 47     # 혼잡도(1) + 승차(1) + 하차(1) + 시간(7) + 날짜(21) + 노드(16)
hidden_size: 64    # 은닉층 크기
output_size: 1     # occupancy (혼잡도만 예측)
num_layers: 2      # 인코더/디코더 각 2층
diffusion_steps: 3 # K=3 (3단계 확산)
use_attention: true
dropout: 0.1
```

### 9.2 데이터 흐름 구조

**입력 → 출력 변환**:
```python
입력: [batch_size, 12, 22, 31]  # 과거 12시간, 22개 역, 31개 특성
    ↓ (특성 결합: 혼잡도+승차+하차+시간+날짜)
특성 확장: [batch_size, 12, 22, 47]  # 노드 특징 추가
    ↓
인코더: 2층 DCGRU → [batch_size, 12, 22, 64]
    ↓
어텐션: Context 생성 → [batch_size, 22, 64]
    ↓
디코더: 2층 DCGRU → [batch_size, 1, 22, 64]
    ↓
출력: [batch_size, 1, 22, 1]   # 미래 1시간, 22개 역, 혼잡도
```

### 9.3 핵심 컴포넌트

**1. Diffusion Convolution**
```python
# 그래프 확산 합성곱 수식
X *_G f_θ = Σ(k=0 to K-1) [θ_k,1 * (D_O^-1 * W)^k + θ_k,2 * (D_I^-1 * W^T)^k] * X

# 특징
- K=3: 3단계 확산 (인근 3개 역까지 영향)
- Forward/Backward: 양방향 정보 전파
- 그래프 구조: 22×22 인접행렬 활용
```

**2. DCGRU Cell**
```python
# Diffusion Convolutional GRU
reset_gate = σ(DiffConv(x) + DiffConv(h))
update_gate = σ(DiffConv(x) + DiffConv(h))
candidate = tanh(DiffConv(x) + DiffConv(reset * h))
new_h = (1 - update) * h + update * candidate
```

**3. Attention Mechanism**
- **Query**: 디코더 은닉 상태
- **Key/Value**: 인코더 출력 시퀀스
- **효과**: 중요한 시점에 집중하여 예측 정확도 향상

### 9.4 학습 설정

**손실 함수** (혼잡도 전용):
```python
Loss = MAE(occupancy)  # 혼잡도만 예측

# 정규화된 값으로 학습 후 역변환
occupancy_normalized = (log1p(occupancy) - mean) / std
loss = |predicted_normalized - target_normalized|
```

**최적화 설정**:
- **옵티마이저**: Adam (lr=0.001, weight_decay=1e-5)
- **스케줄러**: CosineAnnealingLR (T_max=100, eta_min=1e-6)
- **Teacher Forcing**: 0.7 → 0.1 (50 에포크에 걸쳐 감소)
- **그래디언트 클리핑**: max_norm=1.0
- **Early Stopping**: patience=10, min_delta=0.001

**Node Features 정규화**:
```python
# 입력 스케일 불일치 문제 해결
node_features_log = log1p(node_features + 1e-6)
node_features_norm = (node_features_log - mean) / std
```

### 10.3 주요 해결 사항

**1. 역별 고정값 문제 해결**:
- **문제**: 초기 모델이 역별로 고정된 값만 예측
- **원인**: Node features 스케일이 과도하게 커서 다른 입력 압도
- **해결**: Node features Log1p + 정규화 적용
- **결과**: 모든 역이 다양한 예측값 생성 (표준편차 평균 0.393)

**2. 입력 스케일 불일치 해결**:
- **문제**: Node features (0~14069) vs X 데이터 (-3.8~10.4) 스케일 차이
- **해결**: Node features 정규화로 입력 스케일 통일
- **결과**: Encoder가 배치별 차이를 제대로 구분 (차이 0.345)

**3. 모델 Collapse 방지**:
- **방법**: Teacher forcing + 디코더 입력 노이즈 추가
- **결과**: 학습 안정성 확보
