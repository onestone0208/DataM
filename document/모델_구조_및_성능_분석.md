```

├── 시계열 입력: [B, 12, 22, 31]
│   ├── 혼잡도: [B, 12, 22, 1] (Log1p + Z-score 정규화)
│   ├── 승차: [B, 12, 22, 1] (Sqrt 정규화)
│   ├── 하차: [B, 12, 22, 1] (Sqrt 정규화)
│   ├── 시간 특성: [B, 12, 22, 7] (각 시점별 다른 시간 특성)

└── (날짜 특성, 시간 특성은 시계열 입력에 포함됨)

⬇️ 특성 결합 (_augment_features)
📈 통합 입력: [B, 12, 22, 47] (31+16)

⬇️ DCRNN 인코더 (3층)

⬇️ Attention 메커니즘
🎯 컨텍스트: 중요한 시점에 집중

⬇️ DCRNN 디코더 (1스텝)
📊 예측: [B, 1, 22, 1] (혼잡도)
```

### 2. 핵심 혁신 요소

#### A. Diffusion Convolution (공간 모델링)
```python
# 그래프 확산을 통한 공간 의존성 학습
X *_G f_θ = Σ(k=0 to K-1) [θ_k,1 * (D_O^-1 * W)^k + θ_k,2 * (D_I^-1 * W^T)^k] * X
```
- **Forward 확산**: 인접 역으로의 영향 전파
- **Backward 확산**: 역방향 영향 고려
- **K=3 스텝**: 3홉 이내 역들의 상호작용

#### B. DCGRU Cell (시공간 통합)
```python
# GRU + Diffusion Convolution
reset_gate = σ(DiffConv(x) + DiffConv(h))
update_gate = σ(DiffConv(x) + DiffConv(h))
candidate = tanh(DiffConv(x) + DiffConv(reset * h))
```
- **시간적 기억**: GRU의 게이트 메커니즘
- **공간적 확산**: 각 게이트에 Diffusion Convolution 적용

#### C. 승하차 기반 혼잡도 예측
```python
# 혼잡도 변화의 직접적 원인 모델링
승차 ↑ → 혼잡도 ↑  (역 내 인원 증가)
하차 ↑ → 혼잡도 ↓  (역 내 인원 감소)
통행량 = 승차 + 하차 (혼잡도와 무관)
```

#### D. 시계열 시간 특성
```python
# 각 시점별로 다른 시간 특성 (정적 조건 → 진짜 시계열)
t=0 (05시): 새벽시간 특성
t=1 (06시): 출근 시작 특성  
t=2 (07시): 출근 피크 특성
...
t=11 (16시): 퇴근 준비 특성
```

#### E. 다중 특성 통합
```python
# 시계열 + 정적 특성 결합
시계열: 혼잡도(1) + 승차(1) + 하차(1) + 시간특성(7) + 날짜특성(21) = 31차원
정적특성: 노드특성(16) = 16차원
총합: 31 + 16 = 47차원
```

## 📊 데이터 처리 파이프라인

### 1. 정규화 전략
```python
# 혼잡도: Log1p + Z-score 정규화
log_occupancy = log1p(occupancy)  # 0~3539 → 0~8.17
normalized_occ = (log_occupancy - mean) / std  # 표준화

# 승하차: Sqrt 정규화 (0 근처 값이 많음)
normalized_boarding = sqrt(boarding) / 15.0
normalized_alighting = sqrt(alighting) / 15.0
```
- **혼잡도**: Log1p + Z-score (큰 값의 영향 완화)
- **승하차**: Sqrt 정규화 (0 근처 분포 특성 고려)

### 2. 계절별 균등 분할
```python
# 각 월별로 70:15:15 분할
for month in [1,2,...,12]:
    month_data → train(70%) + val(15%) + test(15%)
```
- **계절 편향 방지**: 모든 월이 train/val/test에 포함
- **재현성**: seed=42로 고정

### 3. 특성 구성

## 🎯 훈련 전략

### 1. Teacher Forcing 스케줄링
```python
# 점진적 감소: 1.0 → 0.0 (10 에포크에 걸쳐)
ratio = 1.0 - (epoch / 10) * 1.0
```
- **초기**: 100% 실제값 사용 (안정적 학습)
- **후기**: 0% 실제값 사용 (자율 예측 능력)
- **빠른 감소**: 디코더 collapse 방지를 위해 10 에포크로 단축 (150 → 10)

### 2. 가중 MAE 손실 (균형 조정)
```python
# 큰 혼잡도에 적절한 가중치 (과도한 bias 억제)
weights = 1.0 + 0.5 * (raw_target / 300.0)  # alpha=0.5, C=300
loss = weights * |pred - target|
```
- **균형잡힌 학습**: 피크 시간 중요도 + 평균값 수렴 억제

### 3. 성능 최적화
```python
# 승하차 데이터 사전 처리 (1000배 빨라짐)

batch_size = 16  # CPU 부하 감소

```
- **빠른 데이터 로딩**: DataFrame 필터링 → 딕셔너리 조회
- **안정적인 훈련**: CPU 과부하 방지

## 🔧 주요 기술적 해결 과제

### 1. 시간 특성 시계열화 (최신 개선)
**문제**: `time_features`가 정적 조건으로만 사용됨 (전체 시퀀스에 동일한 시간 특성 복제)
**해결**: `_build_timestep_features` 함수로 각 timestep별 실제 시간 특성 생성
- 각 시점(t=0~11)마다 `start_hour + t`로 실제 hour 계산
- 시간 패턴 학습 가능 (출근→점심→퇴근 흐름)
**효과**: 예측 범위 33배 확장 ([1.1, 5.8] → [0.0, 144.7]명)

### 2. Teacher Forcing 스케줄 최적화
**문제**: `decay_epochs: 150`으로 너무 느린 감소 → 디코더 collapse
**해결**: `decay_epochs: 10`으로 빠른 감소 → 디코더 자율 예측 능력 강화
**효과**: R² 음수(-0.122) → 양수(0.197)로 전환

### 3. 날짜 특성 통합 구조 개선
**문제**: `date_features`가 별도로 전달되어 차원 불일치 (68차원)
**해결**: 날짜 특성을 시계열 입력 `X`에 직접 포함 (31차원)
**효과**: 차원 일관성 확보, 모델 구조 단순화

### 4. Best Model vs Latest Model
**문제**: 마지막 에포크 ≠ 최고 성능 모델
**해결**: Best 체크포인트 우선 로드 → 성능 안정성 확보

### 5. MAPE 폭발 문제
**문제**: 0명 근처에서 MAPE 수백만% 폭발
**해결**: 20명 이상 구간만 계산 → 합리적 지표

### 6. 정규화 통계 일관성
**문제**: Train/Val/Test 간 정규화 통계 불일치
**해결**: Train 통계를 Val/Test에 공유 → 평가 일관성
